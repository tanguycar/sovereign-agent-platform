== Deployment View

=== 1. Infrastructure Level 1: Regional Network Topology

The overall system is deployed within a single, highly isolated Virtual Private Cloud (VPC) spanning multiple Availability Zones (AZ) to ensure high availability without compromising the closed network perimeter. The separation of subnets enforces a strict boundary between the compute layer and the AWS API entry points.

|===
| Component | AWS Resource | Deployment & Isolation Rationale

| **Corporate Access & Inspection**
| AWS Direct Connect + AWS Network Firewall
| Provides a dedicated, private physical fiber connection. All ingress and **egress** traffic between the corporate network and the agentic orchestrator passes through **AWS Network Firewall** for Layer 7 Deep Packet Inspection, ensuring the agent cannot execute unauthorized REST payloads toward internal legacy systems.

| **Agentic Compute Layer**
| AWS Fargate / Step Functions
| Deployed exclusively across **App Private Subnets** in multiple Availability Zones. Step Functions manages the long-running agentic state (waiting for HITL approval), while Fargate provides the ephemeral execution environments.

| **FinOps LLM Gateway Proxy**
| AWS Fargate (Proxy) + Amazon ElastiCache
| An internal routing layer placed in front of Bedrock. The Fargate proxy intercepts agentic queries to provide **Semantic Caching (ElastiCache)**, drastically reducing duplicate token processing costs. It enforces hard token quotas per engineering project, resolving the primary FinOps unpredictability associated with autonomous agents.

| **API Interfaces**
| AWS PrivateLink (Interface Endpoints)
| Deployed in dedicated **Endpoints Private Subnets**. These inject Elastic Network Interfaces (ENIs) with private IP addresses into the VPC, securely bridging the internal gateway to Amazon Bedrock, Secrets Manager, OpenSearch, and KMS.

| **Storage Routing**
| Amazon S3 Gateway Endpoint
| Attached at the VPC Route Table level. Routes heavy document retrieval traffic internally via the AWS SDN instead of PrivateLink, maintaining air-gapped isolation without incurring data transfer processing costs.

|===


=== 7.2 Infrastructure Level 2: Micro-Segmentation & Security Groups

To enforce a Zero-Trust architecture within the VPC boundary, the deployment utilizes strict **Security Group (SG) chaining** and **VPC Endpoint Policies (VPCe)**. This configuration guarantees that even if the ephemeral compute layer is compromised, lateral movement or data exfiltration to unauthorized systems is cryptographically and logically impossible at the network interface level.
