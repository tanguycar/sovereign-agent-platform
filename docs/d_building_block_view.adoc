== Building Block View

The Building Block View explains the static decomposition of the Sovereign Agentic Platform. It opens the "black box" defined in the System Context (Section 3) to reveal the internal subsystems, their responsibilities, and their interfaces.

=== 1 Whitebox Overall System (Level 1)

At the highest level of abstraction, the agentic platform is decomposed into five logical layers. This modularity ensures a strict separation of concerns between state orchestration, pure cognitive reasoning, enterprise execution, and cryptographic governance.

The following table details the functional accountability of each building block within the air-gapped perimeter.

[cols="22%,43%,35%",options="header"]
|===
| Building Block | Core Responsibility | Key Technologies

| **1. Agentic Orchestration Layer**
| "Control Plane". Maintains execution state and routes data without embedding cognitive logic.
| AWS Fargate / Step Functions.

| **2. Cognitive Engine Layer**
| "Reasoning Engine". Formulates execution plans under a strict Zero Data Retention (ZDR) policy.
| Amazon Bedrock (Mistral Large 3).

| **3. Knowledge & Retrieval Pipeline**
| Context retrieval system. Enforces Attribute-Based Access Control (ABAC) before vector fetching.
| Amazon S3, OpenSearch Serverless, Amazon Titan.

| **4. Tools & Action Layer**
| "Execution Engine". Executes corporate API calls post-HITL validation using strictly ephemeral tokens.
| Custom integration modules on AWS Fargate.

| **5. Trust, Security & Secrets Plane**
| Transversal governance. Provisions dynamic secrets, filters prompts, and exports immutable audit logs to the SIEM.
| AWS Secrets Manager, KMS (CMK), Bedrock Guardrails, CloudTrail.
|===
