== Building Block View

The Building Block View explains the static decomposition of the Sovereign Agentic Platform. It opens the "black box" defined in the System Context (Section 3) to reveal the internal subsystems, their responsibilities, and their interfaces.

=== 1 Whitebox Overall System (Level 1)

At the highest level of abstraction, the agentic platform is decomposed into six logical layers. This modularity ensures a strict separation of concerns between state orchestration, LLM traffic governance, pure cognitive reasoning, enterprise execution, and cryptographic security.

The following table details the functional accountability of each building block within the air-gapped perimeter.

[cols="22%,43%,35%",options="header"]
|===
| Building Block | Core Responsibility | Key Technologies

| **1. Agentic Orchestration & State Layer**
| "Control Plane". Maintains execution state, manages agentic loops, and orchestrates data flow. Strictly forbidden from calling cognitive APIs directly.
| AWS Fargate, AWS Step Functions.

| **2. LLM Governance & Cache Layer**
| "Inference Choke Point". Mandatory internal proxy for all LLM and embedding requests. Enforces semantic caching, FinOps rate-limiting, and centralizes routing.
| Internal Proxy (e.g., LiteLLM/Envoy), Amazon ElastiCache (Redis).

| **3. Cognitive Engine Layer**
| "Reasoning Engine". Formulates execution plans under a strict Zero Data Retention (ZDR) policy. Subject to centralized Guardrails upon cache miss.
| Amazon Bedrock (Mistral Large 3), Bedrock Guardrails.

| **4. Knowledge, Data & Retrieval Pipeline**
| "Context & Artifacts". Enforces Attribute-Based Access Control (ABAC) for vector retrieval and provides isolated storage for agentic artifacts.
| Amazon S3, Amazon OpenSearch Serverless, Amazon Titan (Embeddings).

| **5. Tools & Action Layer**
| "Execution Engine". Executes corporate API calls post-HITL (Human-in-the-Loop) validation using strictly ephemeral tokens.
| Custom integration modules on AWS Fargate.

| **6. Trust, Security & Secrets Plane**
| Transversal governance. Provisions dynamic secrets, enforces KMS encryption (CMK), and exports immutable audit logs to the corporate SIEM.
| AWS Secrets Manager, AWS KMS (CMK), AWS CloudTrail.
|===
