=== Technical Context

The technical context defines the physical and network infrastructure, transport protocols, and data payloads exchanged between the Sovereign Agentic Platform and its external dependencies. The interactions below explicitly map the communication interfaces, demonstrating strict adherence to the zero-public-internet (air-gapped) constraints.

|===
|Interface / Channel |Source -> Target |Protocol & Security |Data Format |Isolation Mechanism

|*Identity & ABAC Claims*
|Corporate IdP -> Orchestrator
|HTTPS (TLS 1.3), TCP 443 over 802.1Q VLAN (BGP)
|OIDC / JWT Claims
|Dedicated private fiber (AWS Direct Connect); zero public Internet routability.

|*Document Push (Sync)*
|PLM Agent -> Amazon S3
|HTTPS (TLS 1.3), TCP 443 over 802.1Q VLAN (BGP)
|Binary Stream (PDF, CAD)
|AWS Direct Connect to S3 Interface Endpoint; bypasses the public internet completely.

|*Cognitive & Vector Search*
|Orchestrator -> Bedrock & OpenSearch
|HTTPS (TLS 1.2+), AWS SigV4, TCP 443 via PrivateLink
|JSON (Prompts, Embeddings)
|VPC Interface Endpoints (local ENIs). Traffic is cryptographically sealed on the AWS private backbone.

|*State & Secrets Retrieval*
|Orchestrator -> DynamoDB & Secrets Manager
|HTTPS (TLS 1.2+), AWS SigV4, TCP 443 via PrivateLink
|JSON (Ephemeral tokens, state)
|VPC Interface Endpoints. Enforces strict zero-trust machine-to-machine authentication.

|*Document Retrieval*
|Orchestrator -> Amazon S3
|HTTPS (TLS 1.2+), AWS SigV4, TCP 443 via Gateway
|Binary Stream
|VPC Route Table prefix list redirection (Gateway Endpoint); no transit outside the internal network.

|*Action Execution (Egress)*
|Orchestrator -> CI/CD & ITSM
|HTTPS (TLS 1.3), REST API (TCP 443) via Direct Connect
|JSON (Pipelines, Tickets)
|Outbound connection initiated internally using strictly scoped ephemeral tokens; routed over private Direct Connect.

|*Security & Audit Export*
|CloudWatch -> Corporate SIEM
|Log Forwarding / Syslog over TLS via Direct Connect
|JSON / CEF
|Log streams pushed directly to corporate on-premises infrastructure via dedicated private lines.
|===
