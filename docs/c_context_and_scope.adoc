=== Technical Context

The technical context defines the physical and network infrastructure, transport protocols, and data payloads exchanged between the Sovereign Agentic Platform and its external dependencies. The interactions below explicitly map the communication interfaces, demonstrating strict adherence to the zero-public-internet (air-gapped) constraints.

[cols="18%,22%,24%,16%,20%",options="header"]
|===
|Interface / Channel |Source -> Target |Protocol & Security |Data Format |Isolation Mechanism

|Identity & ABAC Claims
|Corporate IdP -> Perimeter -> Orchestrator
|HTTPS (TLS 1.3), TCP 443 over 802.1Q VLAN (BGP)
|OIDC / JWT Claims
|Dedicated private fiber (Direct Connect). Traffic is strictly inspected by AWS Network Firewall (Perimeter) before reaching Fargate.

|Document Push (Sync)
|PLM Agent -> Perimeter -> Orchestrator -> Amazon S3
|HTTPS (TLS 1.3) to API, then AWS SigV4 to S3
|Binary Stream (PDF, CAD)
|Ingress inspected by ANFW. Direct Connect cannot route to S3 Gateway directly; Orchestrator proxies the upload via internal VPC route tables.

|Cognitive Intelligence
|Orchestrator -> LLM Gateway -> Bedrock
|TCP 4000 (Internal), then HTTPS (TLS 1.2+) via PrivateLink
|JSON (Prompts, Embeddings)
|Strict SG chaining. Gateway enforces logic/cache. VPC Interface Endpoints seal LLM traffic on the AWS private backbone.

|Vector & Semantic Search
|Orchestrator -> OpenSearch Serverless
|HTTPS (TLS 1.2+), AWS SigV4, TCP 443 via PrivateLink
|JSON (Vectors, Queries)
|VPC Interface Endpoints (local ENIs). No public inbound or outbound routability.

|Secrets & Cryptography
|Orchestrator -> Secrets Manager & KMS
|HTTPS (TLS 1.2+), AWS SigV4, TCP 443 via PrivateLink
|JSON (Keys, Credentials)
|VPC Interface Endpoints. Enforces strict zero-trust machine-to-machine authentication (IAM Task Roles).

|State & Document Retrieval
|Orchestrator -> Step Functions / ElastiCache / S3
|AWS API / TCP 6379 / HTTPS via S3GW
|JSON / Binary
|VPC internal routing and Gateway Endpoint (prefix lists). Subnet-level isolation ensuring no transit outside the VPC.

|Action Execution (Egress)
|Orchestrator -> Perimeter -> CI/CD & ITSM
|HTTPS (TLS 1.3), REST API (TCP 443)
|JSON (Pipelines, Tickets)
|Outbound initiated internally. Routed via Direct Connect and explicitly whitelisted by AWS Network Firewall stateful rules.

|Security & Audit Export
|CloudWatch -> Lambda/Firehose Forwarder -> Perimeter -> Corporate SIEM
|HTTPS / Syslog over TLS via Direct Connect
|JSON / CEF
|Log streams are actively pushed by a forwarder through the Network Firewall to the on-premises infrastructure.
|===
